# FoodBae

FoodBae is a full-stack MERN food ordering application.

## Features

- User registration and login
- Restaurant browsing
- Food selection and cart
- Quantity management
- Offers and coupons
- Order management
- Payment integration
- Image management

## Tech Stack

- React
- Redux
- Node.js
- Express
- MongoDB
- Tailwind CSS
- Cloudinary
- Stripe
- JWT authentication

## Project Structure

- `frontend/` – React application
- `backend/` – Express/Node.js API

## My Work

Built the application end-to-end, including the frontend UI, API integration, authentication flow, database models, cart/order functionality, and payment integration.
